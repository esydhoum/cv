## 2. Наблюдаемые требования (прямо подтверждаются текстом документа)

### 2.1. Цель и задачи курсовой (по методичке)

- Используются **вторичные и первичные** источники.

- Тема выбирается студентом самостоятельно и **согласовывается с преподавателем**.

### 2.3. Обязательная композиция работы

Как правило, работа включает:
1. титульный лист (макет — в Приложении А; **в предоставленном файле Приложение А отсутствует**);
2. содержание (все разделы/главы/параграфы с номерами страниц начала);

Структура конкретной работы **может быть согласована с руководителем**.

### 2.4. Требования к введению

Введение должно содержать:
1. **Обоснование актуальности** на основе постановки проблемы исследования:
   - проблема ≠ тема;
   - тема задаёт предмет; проблема — разрыв между желаемым и действительным состоянием предмета;
   - различать проблему бизнеса и исследовательскую проблему;
   - описать суть, значимость, рамки, разработанность; выдвинуть возможные гипотезы истоков проблемы;
2. **Цель** работы по решению проблемы и **задачи** исследования;
3. **Объект**, **предмет** и **обоснование методов**;
4. **Описание общей структуры** работы.

*Примечание в методичке:* «Для данной курсовой работы проблема определяется как рыночная составляющая в проблеме магистерской диссертации» — формулировка выглядит как след общей шаблонной методички; для бакалаврской курсовой её применимость нужно уточнять у руководителя.

### 2.5. Глава 1 — теоретическая

**Назначение:** оценка суммы знаний по теме; аналитический обзор литературы; сравнение позиций авторов; выбор собственной позиции; отдельный параграф — методы/методики исследования; на их основе — свой подход для конкретного объекта.

### 2.10. Критерии оценки (наблюдаемые)

**Итоговая шкала (% от максимума):**
- 0–50 % — неудовлетворительно  
- 51–69 % — удовлетворительно  
- 70–84 % — хорошо  
- 85–100 % — отлично  

**Балльная схема (0–5 по блокам):**

2. практическая часть (методика, поиск/обработка информации, выводы, предложения);
3. оформление;
4. защита (доклад, презентация, ответы).

Детализированная рубрика (0 / 3 / 4 / 5) включает: актуальность; теорию; методическую грамотность; экономическое обоснование решений; практическую значимость; оформление; качество защиты.
